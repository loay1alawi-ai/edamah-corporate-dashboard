        Scoring Rules

        Each KPI receives a performance score from 1 to 5 based on how far its actual result is above or below target. Adjust the % ranges below to redefine each status; every score, rollup and chart updates automatically.

        Performance Status by % Difference from Target

        Pillar and overall scores are the weight-averaged KPI scores. Their status is the nearest whole score (e.g. 2.5 to 3.49 reads as Meets target).

        KPIs Where Lower Is Better

        Operating Cost Variance and Average Schedule Variance improve as they fall. This dashboard always flips the % difference for these two KPIs, so that 10% below target counts as +10% and 10% above target counts as −10%, on the same scale as every other KPI.

        KPIs With No Result in the Month

        A missing result is always excluded from scoring for that period, and the remaining weights are reweighted so the KPIs that did report still sum to 100%.
